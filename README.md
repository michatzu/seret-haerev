# סרט הערב

מה מוקרן לידך היום, בכל בתי הקולנוע בישראל, במקום אחד. רשימה מינימליסטית של סרטים לפי קרבה, שעה ו-IMDb, ולחיצה על שעה פותחת ישירות את בחירת המושבים באתר בית הקולנוע.

## איך זה עובד

- `npm run scrape` — אוסף את כל ההקרנות מהרשתות (פלאנט, רב חן, סינמה סיטי, הוט סינמה, מובילנד, לב), מהסינמטקים (תל אביב, ירושלים, חיפה, חולון, הרצליה, שדרות) מהקולנוע הזמני (גן הפסגה, בית רדיקל ועוד) מפסטיבלים (חיפה) ומאולמות קטנים (ראש פינה, אילת, תיאטרון ירושלים ועוד), מאחד סרטים בין הרשתות, מעשיר אותם מ-TMDB אם יש מפתח ומוסיף ציוני IMDb מהמאגר הרשמי, ושומר ל-`data/snapshot.json`.
- `npm run dev` — האתר (Next.js, App Router). קורא את הקובץ ומחשב מרחקים מהמיקום של המשתמש.
- הפוסטרים עוברים דרך `/api/poster/[id]`: הוא מנסה את כל המקורות שנאספו לאותו סרט לפי הסדר, שולח לכל רשת Referer משלה (לב חוסמת הטמעה חיצונית), ומחזיר תמונת ברירת מחדל אם הכול נכשל.
- המיקום: עוגיית `loc` (נבחרת בכפתור המיקום), אחרת העיר לפי כתובת ה-IP (כותרות של Vercel), אחרת תל אביב.
- הסינון חי בכתובת: `?day=today|tomorrow|d2|d3|week|month&from=now|noon,evening|all&r=5|15|30|all&hall=imax,vip,4dx,screenx,3d,cinematheque,outdoor&v=<venue ids>&g=<genre keys>&sort=dist|time|imdb&kids=1&far=1`.

### אולמות קטנים

`src/scraper/smarticket.ts`. רוב המקומות הקטנים בארץ מוכרים דרך SmarTicket, וכל דייר עונה באותו `\/api\/shows`. לכן מפרסר אחד מכסה את ראש פינה, אילת, טיקוטין, מעלות, סביון, רחובות, כפר סבא, רעננה, רמת השרון ונהריה, והוספת מקום חדש עולה שורות בודדות בטבלה. דייר שאינו קיים מחזיר 200 עם רשימה ריקה, לא שגיאה.

תיאטרון ירושלים נמצא ב-`festivals.ts`: הלוח שלו ב-`na_ajax.php?action=getBoard`, והמספר שנראה כמו חותמת זמן הוא בעצם שעון מקומי.

### פסטיבלים

`src/scraper/festivals.ts`. פסטיבל הוא בית קולנוע שקיים תשעה ימים, באולמות שאינם בתי קולנוע בשאר השנה. פסטיבל חיפה מפרסם את כל לוח ההקרנות בעמוד אחד, כך שהוא עולה בקשה אחת: 215 הקרנות, שבעה אולמות ובהם מוזיאון, מועדון ורחבה פתוחה. הקואורדינטות של האולמות מתוחזקות בקובץ עצמו.

### קולנוע זמני

הקרנות במקומות שאינם בתי קולנוע מגיעות משני מקורות ב-`src/scraper/popup.ts`:

- **עיריית תל אביב** (`GetEvBenList`) — שמות סרטים בעברית ושעות מדויקות למקומות עירוניים כמו גן הפסגה. השירות מחזיר רשימה ריקה אם גוף הבקשה חסר, לכן הוא נשלח במלואו.
- **Secret Tel Aviv** (הזנת iCal ציבורית) — מכסה את המקומות העצמאיים, באנגלית.

שניהם בלתי מתועדים. כישלון של אחד מהם מדווח ולא מפיל את הסריקה. הקואורדינטות של המקומות מתוחזקות ידנית בקובץ עצמו.

### הרשימות של המשתמש

שלוש רשימות — רוצה לראות, צפיתי, לא מעניין — וסרט נמצא לכל היותר באחת מהן, לכן מדובר בסטטוס אחד לסרט (`src/lib/filmLists.ts`). הכל נשמר ב-`localStorage` במפתח `film-lists` בלבד. הסתרת הסרטים נעשית בגיליון סגנון אחד (`ListStyles`) ולא ברכיב לכל כרטיס, כדי שהרשימה תישאר מרונדרת בשרת. בנייד החלקה ימינה מוסיפה ל״רוצה לראות״ ושמאלה ל״לא מעניין״ (`SwipeToFile`); הכיוונים פיזיים ולא לפי כיוון הכתיבה.

## מבנה

```
scripts/scrape.ts        הרצת כל המתאמים וכתיבת ה-snapshot
src/scraper/             מתאם לכל מקור (cineworld, modulus, lev, cinematheques, popup), normalize, tmdb
src/data/venues.ts       בתי הקולנוע וקואורדינטות
src/lib/                 טיפוסים, זמן (Asia/Jerusalem), גיאוגרפיה, סינון ומיון (query.ts), טעינת נתונים
src/app/                 עמודים: / (הרשימה), /film/[id] (דף סרט), /api/poster/[id] (פרוקסי פוסטרים)
src/components/          רכיבי UI
```

## הגדרות

העתיקו את `.env.example` ל-`.env.local`:

- `TMDB_API_KEY` — פוסטרים, תקצירים בעברית, מדינה, שנה, במאי ושחקנים ([themoviedb.org](https://www.themoviedb.org/settings/api), חינם).
- ציון IMDb מגיע ישירות ממאגר הנתונים היומי של IMDb (title.ratings), בלי מפתח; צריך רק את מזהה ה-IMDb שמגיע מ-TMDB.

בלי המפתחות האתר עובד, רק עם פחות מידע על הסרטים.
