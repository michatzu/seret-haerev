# IBM Plex Sans Hebrew

The same face the site itself uses, kept here as TTF because the share image is drawn by Satori,
which reads `ttf`/`otf`/`woff` only — never the `woff2` that `next/font` downloads. Without it the
renderer has no Hebrew glyphs of its own and goes out to Google Fonts mid-build for them.
